# 第三階段－層級二：規則式融合

## 實驗目的

層級二根據單一專家模型的預測品質資訊，以及專家模型之間的一致性，為不同個案選擇或融合較可靠的結果。此階段使用預先定義的規則，不進行自主決策或線上學習。

## 規則所需資訊

### 單一專家模型特徵

針對每個專家模型計算：

- **信心分數：** 病灶區域內的平均／分位數預測機率，或模型整體信心摘要。
- **病灶體積：** 預測病灶的總體積。
- **連通區塊：** 預測病灶的連通區塊數量及各區塊大小。
- **機率統計：** 最大值、平均值、標準差、熵等機率分布資訊。

### 跨專家模型特徵

比較不同專家模型的預測結果：

- **成對 Dice：** 任兩個專家模型分割遮罩的重疊程度。
- **成對 IoU：** 任兩個專家模型的交並比。
- **聯集／交集比例：** 所有預測聯集與交集的體積比例。
- **分歧程度：** 專家模型在體素／像素或病灶層級上的分歧程度。

## 規則設計原則

1. **高一致性案例：** 當專家模型間的成對 Dice／IoU 高且分歧低時，採用層級一表現最佳的固定融合結果。
2. **低信心案例：** 當整體信心分數過低時，標記為不確定案例，避免直接接受單一專家模型的結果。
3. **體積異常案例：** 當某個專家模型的病灶體積明顯偏離其他專家模型時，降低其權重或排除該預測。
4. **離散假陽性案例：** 當某個專家模型產生大量微小連通區塊時，可降低其權重或先進行規範化後處理。
5. **高分歧案例：** 當聯集／交集比例或分歧程度過高時，選擇驗證集上較可靠的專家模型、使用保守融合策略，或標記為需進一步仲裁。

所有閾值、權重與規則優先順序皆須由訓練／驗證資料決定，測試集僅用於最終評估。

## 規則流程

```text
輸入四個專家模型的機率圖與遮罩
                    │
                    ▼
計算單一與跨專家模型特徵
                    │
                    ▼
檢查信心、體積、連通區塊與一致性規則
                    │
                    ▼
選擇專家模型／調整權重／套用固定融合／標記不確定案例
                    │
                    ▼
輸出最終分割與規則觸發紀錄
```

## 評估方式

- 與最佳單一專家模型及層級一最佳固定融合方法比較。
- 使用 Dice、Sensitivity、HD95、Precision 與 Specificity 評估最終分割。
- 額外統計各規則的觸發次數、觸發後效能變化與不確定案例比例。
- 進行規則消融實驗，逐一移除規則以分析各項特徵的貢獻。

# 第二階段：注意力模組比較

## 實驗目的

第二階段以第一階段勝出的模型作為固定基準，分別加入五種注意力模組，比較不同注意力機制對分割表現的影響，並選出適合進入第三階段融合的模型版本。

## 注意力候選配置

| 注意力模組 | 類型 | 主要作用 |
| --- | --- | --- |
| SE | 通道注意力 | 重新校準各通道的重要性 |
| CBAM | 通道＋空間注意力 | 依序建模通道與空間資訊 |
| ECA | 輕量通道注意力 | 以低額外成本建立局部跨通道互動 |
| CA | 通道＋空間注意力 | 同時保留通道關係與位置資訊 |
| MHSA | 全域自注意力 | 建模長距離與全域空間關係 |

另保留一組未加入注意力的基準模型作為對照組。

## 實驗設計

- **固定骨幹：** 使用第一階段的勝出模型。
- **固定訓練流程：** 沿用第一階段的資料切分、前處理、資料增強、訓練週期、損失函數、最佳化器、學習率排程、推論及評估方式。
- **單一變因：** 每次實驗只替換注意力模組。
- **插入位置：** 依骨幹架構選擇合理位置；同一注意力模組在所有重複實驗中必須保持一致。
- **重複實驗：** 使用相同隨機種子或相同次數的重複實驗，回報平均值與標準差。

> 不同注意力模組的結構與計算方式不同，因此插入位置不必完全相同，但必須事先定義並完整記錄，避免依測試結果反覆調整。

## 評估方式

- 主要指標：Dice、Sensitivity。
- 次要指標：HD95、Precision、Specificity。
- 效率指標：參數量、FLOPs、推論時間與 GPU 記憶體用量。

除整體測試結果外，亦比較每個注意力版本相對於基準模型的變化量，確認效能提升是否足以抵銷額外計算成本。

## 第三階段專家模型選擇原則

1. `expert 0` 固定為未加入注意力的基準模型。
2. 依驗證集的 Dice 與 Sensitivity，從五個注意力版本中選出三個互補且表現穩定的版本，作為 `expert 1`～`expert 3`。
3. 若模型表現接近，優先考慮錯誤型態具有互補性者，而非只依單一平均分數排序。
4. 專家模型組合確認後，不得依測試集結果更換成員或調整設定。

## 預期產出

- 基準模型與五種注意力配置的完整比較結果。
- 注意力插入位置與額外計算成本紀錄。
- 第三階段使用的四個專家模型：一個基準模型與三個注意力強化模型。
